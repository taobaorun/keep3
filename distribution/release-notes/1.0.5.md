# Keep3 1.0.5

## Before first launch

Keep3 1.0.5 is distributed without Apple Developer ID notarization. It keeps
macOS quarantine enabled and does not bypass Gatekeeper.

1. Open Finder and go to **Applications**.
2. Control-click **Keep3**, choose **Open**, then confirm **Open**.
3. If macOS still blocks it, open **System Settings → Privacy & Security** and
   choose **Open Anyway**.

This confirmation is normally required only once. The DMG also contains a
Chinese first-launch guide, and Homebrew prints the same steps after install.

## Install

With Homebrew:

```sh
brew install --cask taobaorun/keep3/keep3
```

Or download `Keep3-1.0.5.dmg` below. Keep3 requires an Apple silicon Mac running
macOS 14 or later.

## What changed

- Archive priorities without permanently deleting them, review them in the new
  read-only History destination, and export active or archived items as Markdown.
- Refined top-surface sizing, motion, press feedback, keyboard accessibility,
  Settings previews, Reduce Motion behavior, and main-window visual consistency.
- Long compact priority titles now tighten gently and show a tail ellipsis rather
  than being clipped at the surface edge.

The release includes the SHA-256 sidecar, signed release manifest, and GitHub
artifact attestation for independent integrity verification.
