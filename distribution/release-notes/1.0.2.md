# Keep3 1.0.2

## Before first launch

Keep3 1.0.2 is distributed without Apple Developer ID notarization. It keeps
macOS quarantine enabled and does not bypass Gatekeeper.

1. Open Finder and go to **Applications**.
2. Control-click **Keep3**, choose **Open**, then confirm **Open**.
3. If macOS still blocks it, open **System Settings → Privacy & Security** and
   choose **Open Anyway**.

This confirmation is normally required only once. The DMG also contains a
Chinese first-launch guide, and Homebrew prints the same steps after install.

## Install

With Homebrew:

```sh
brew install --cask taobaorun/keep3/keep3
```

Or download `Keep3-1.0.2.dmg` below. Keep3 requires an Apple silicon Mac running
macOS 14 or later.

## What changed

- Refined the Calendar surface with a clearer primary-event card and a calmer
  timeline for the remaining upcoming events.
- Made compact and expanded Calendar presentations feel like one coherent
  component, with explicit today and tomorrow grouping.
- Polished loading, empty, permission, and refresh-failure states while keeping
  event times stable and easy to scan.

The release includes the SHA-256 sidecar, signed release manifest, and GitHub
artifact attestation for independent integrity verification.
